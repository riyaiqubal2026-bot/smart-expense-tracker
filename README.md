# Smart Expense Tracker

A REST API built with Spring Boot for learning backend development.

## Technologies

- Java
- Spring Boot
- Spring Web
- Spring Security
- Spring Data JPA
- H2 Database
- Maven

## Getting Started

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Reload the Maven dependencies.
4. Run the main Spring Boot application class.

## Project Status

Work in progress. Database configuration, security, and API features are being developed and tested.
